# Cloud Vault: Статус Реалізації

## Реалізовано

### Основні можливості
- Єдиний інтерфейс для перегляду файлів з усіх підключених хмарних сховищ (дашборд + recent files).
- Екран файлового менеджера сховища з детальним browse по папках (вхід у сховище з дашборду, breadcrumb, перехід між папками).
- Глобальний пошук файлів по всіх сховищах одночасно.
- Візуалізація використання дискового простору (Dashboard + Analytics, графіки, попередження).
- Сповіщення про критичний рівень зайнятого місця у вигляді in-app warning на екрані аналітики (не push).

### Функції / варіанти використання
- Студент переглядає список усіх підключених хмарних сховищ на головному екрані застосунку.
- Фрілансер додає нове хмарне сховище (Google Drive) до застосунку у налаштуваннях застосунку (через connect flow).
- Менеджер проєкту переглядає вільний та зайнятий простір кожного сховища на дашборді застосунку.
- Студент шукає файл за назвою серед усіх підключених сховищ у рядку пошуку застосунку.
- Фрілансер завантажує файл з Google Drive на пристрій у файловому менеджері застосунку (через відкриття download URL).
- Менеджер проєкту видаляє застарілий файл зі сховища у контекстному меню файлу.
- Студент перейменовує файл у хмарному сховищі у діалозі редагування файлу.
- Менеджер проєкту переглядає нещодавно відкриті файли з усіх сховищ на вкладці нещодавніх файлів.
- Фрілансер сортує файли за датою, розміром або типом у файловому менеджері сховища.
- Менеджер проєкту ділиться посиланням на файл з колегою у діалозі спільного доступу.
- Студент позначає важливий файл зірочкою для швидкого доступу у контекстному меню файлу.
- Фрілансер фільтрує файли за типом (документи, зображення, відео) на панелі фільтрів.
- Менеджер проєкту експортує звіт про використання сховищ у PDF на екрані аналітики.
- Студент перемикається між темною та світлою темою у налаштуваннях застосунку.
- Менеджер проєкту відключає хмарне сховище від застосунку у налаштуваннях акаунтів.
- Фрілансер переглядає детальну інформацію про файл (розмір, дата, тип) у діалозі властивостей файлу.
- Фрілансер переглядає рекомендації щодо оптимізації місця у сховищах на екрані аналітики та рекомендацій.

## Не Реалізовано

### Основні можливості
- Крос-хмарне переміщення та копіювання файлів.
- Автоматична синхронізація вибраних папок між сховищами.
- Попередній перегляд файлів без завантаження на пристрій.

### Функції / варіанти використання
- Менеджер проєкту завантажує документ з пристрою на OneDrive у вікні завантаження файлів.
- Студент переміщує файл з Dropbox на Google Drive у контекстному меню файлу.
- Фрілансер копіює папку з OneDrive до iCloud у файловому менеджері застосунку.
- Студент отримує сповіщення про закінчення місця на Dropbox у центрі сповіщень застосунку.
- Студент переглядає попередній перегляд зображення без завантаження у вбудованому переглядачі файлів.
- Фрілансер переглядає статистику використання сховища за місяць на екрані аналітики.
- Менеджер проєкту налаштовує автоматичну синхронізацію папки між сховищами у налаштуваннях синхронізації.
- Студент відновлює видалений файл з кошика сховища у розділі кошика.
- Фрілансер змінює дозволи спільного доступу до файлу у налаштуваннях доступу файлу.
- Студент отримує push-сповіщення про спільний файл, доданий колегою, на екрані блокування телефону.
- Менеджер проєкту виконує масове переміщення файлів між сховищами у режимі множинного вибору.
- Студент налаштовує резервне копіювання фото з пристрою на сховище у налаштуваннях резервного копіювання.

## Частково Реалізовано (Обмеження)
- Download реалізований як відкриття зовнішнього URL, без вбудованого менеджера завантажень.
- Попередження про заповнення місця є в UI аналітики, але немає системних push-сповіщень.
- Є підключення Google Drive / OneDrive / Dropbox / MEGA; iCloud не реалізований.
- Дія `Copy` присутня в меню файлу, але наразі показує `Copy is not configured yet`.
- `Upload` в екрані файлового менеджера зараз UI-заглушка (`Upload is not configured yet`).
